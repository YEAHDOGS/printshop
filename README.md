# DOGS Print Shop

3D-printable assets, designed from real-life annoyances. A YEAHDOGS thing.

**Model:** digital STL file sales first (pure margin, no printer needed),
printed-on-demand later. See `docs/business-model.md`.

## Layout

- `index.html` — landing page (static, GitHub Pages ready)
- `products/` — one page per product
- `assets/` — parametric OpenSCAD sources (`.scad`)
- `docs/research/` — per-product market + print-economics research
- `docs/business-model.md` — the two lanes

## Products
